## 5) الأمان: ما تغيّر فعلاً

1. **صلاحيات CI**: المستوى الأعلى `{}` (منع شامل)، verify قراءة-فقط (`contents: read`) وبلا أي `secrets`، release `contents: write` + `needs: verify` فقط.
2. **إجراءات خارجية مثبّتة بـ SHA** (checkout/setup-java/flutter-action/upload-artifact/gh-release) — بلا وسوم عائمة.
3. **إصدارات GitHub غير قابلة للتعديل**: أُزيل `overwrite_files` وأُضيف حارس وجود الوسم — أُعيد التحقق تجريبياً: الدفع اللاحق (c36e79f) لم يمسّ الإصدار المنشور.
4. **`allowBackup=false`** في القائمة: كان افتراضي `true` يعني تسرب بيانات المتعلم إلى نسخ النظام السحابية — أُصلح (انعكس فعلياً في APK المنشور: القائمة المدمجة `false`).
5. **بوابة الإنتاج**: `workflow_dispatch (production: true)` بلا `key.properties` ⇒ فشل المهمة — لا APK بتوقيع debug يمرّ كإنتاج أبداً. لا تُطبع أي بيانات توقيع.
6. **مسح أسرار**: لا `ghp_`/`AKIA`/مفاتيح خاصة في أي ملف متتبع؛ لا ملفات توقيع في المستودع؛ لا `print()` في `lib/`.
