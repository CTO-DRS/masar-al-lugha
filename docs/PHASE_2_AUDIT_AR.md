## 6) بنود فُحصت ووجدت سليمة (لا تُعدّل — أُثبت الفحص)

- **srs.dart**: مجدول FSRS-4.5 حقيقي بتوثيق صادق (بلا مُحسِّن معاملات — مُعلن). الترتيب، خطوة الـ10 دقائق، الترحيل التكراري، و`hintFor == rate` كلها مثبتة باختبارات سابقة + اختبار عزل النكسة الجديد.
- **calibration.dart**: تقرير معايرة بأعداد عينات صريحة — لا ادعاءات إحصائية بلا بيانات.
- **remediation.dart**: قاعدة «الأيام المميزة» تمنع تضخم النكسات في عصر واحد — مغطاة باختباراتها.
- **الخصوصية**: صلاحيات Manifest كما هي (RECORD_AUDIO/POST_NOTIFICATIONS/VIBRATE فقط)، لا إنترنت، بيانات كل ملف شخصي معزولة (H-2 مُغلق باختباراته).
- **الطيّب الصوتي للخدمات**: `stt.dart`/`tts.dart` تتعامل مع غياب المحرك بتراجع صريح — مثبت بويدجت الاختبار (MissingPlugin → حالة «غير متاح»).
